## ⚡ Quick Start (30 secondi)

1. **Apri Visual Studio**
2. **File → Open → Project/Solution**
3. **Seleziona:** `ClassicAssist.sln` (in questa cartella)
4. **Clicca:** `Build → Rebuild Solution`
5. **Attendi** 2-5 minuti
6. **Esegui:** `Ctrl + F5` per avviare
7. **Goditi** il nuovo tema gotico! 🖤

## 🎓 Impara di Più

**Se vuoi personalizzare il tema dopo:**

1. Apri `ClassicAssist.Shared/Resources/Colours.xaml`
2. Modifica i colori HEX
3. Salva file
4. Ricompila (Build → Rebuild Solution)

Esempio:
```xaml
<!-- Vuoi più viola? -->
<Color x:Key="AccentColor">#A855F7</Color>

<!-- Vuoi rosso gotico? -->
<Color x:Key="AccentColor">#DC2626</Color>
```
