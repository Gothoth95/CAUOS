OPZIONE 2: MANUALE (Se l'automatica non funziona)
═══════════════════════════════════════════════════════════════════════════════

Passo 1: Apri Visual Studio
  Cerca nel Menu Start: "Visual Studio"
  Apri "Visual Studio 2019" o "Visual Studio 2022"

Passo 2: Apri il Progetto
  File → Open → Project/Solution
  Seleziona: ClassicAssist.sln (in questa cartella)
  Clicca: Open

Passo 3: Attendi il Caricamento
  Aspetta che il progetto si carichi completamente (30-60 secondi)

Passo 4: Compila
  Clicca: Build → Rebuild Solution
  Oppure: Premi Ctrl + Shift + B

Passo 5: Attendi Completamento
  La compilazione prenderà 2-5 minuti
  Vedrai: "Build succeeded" al termine

Passo 6: Esegui
  Premi: Ctrl + F5 (Debug → Start Without Debugging)

Tempo: 5-10 minuti totali

RISOLUZIONE PROBLEMI:

❌ Problema: "MSBuild non trovato"
   Soluzione: Installa Visual Studio (link sopra)

❌ Problema: "ClassicAssist.sln non trovato"
   Soluzione: Esegui lo script dalla cartella radice del progetto

❌ Problema: Compilazione fallisce
   Soluzione:
   1. Apri Visual Studio
   2. Controlla la finestra "Error List"
   3. Cerca errori rossi
   4. Contatta supporto se necessario
